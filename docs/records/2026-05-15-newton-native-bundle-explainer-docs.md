## Claim Boundary

This documentation update does not add new experiment evidence. It clarifies that the latest
native bundle is runtime diagnostic-path support for a synthetic package containing `box`,
`sphere`, `capsule`, `cylinder`, `cone`, and `ellipsoid`.

It does not claim full CPD paper reproduction, collision-quality improvement, benchmark
superiority, broad asset coverage, or default CPD-like generator support for the new native kinds.

# ACCV Supplement Tutorial Atlas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a standalone 20+ page ACCV supplementary PDF that teaches reviewers the diagnostic framework with mathematical derivations, implementation details, provenance notes, and new supplement-only visual plates.

**Architecture:** Keep the main ACCV PDF untouched and add `paper/venues/accv/supplement.tex` as a separate ACCV/LNCS entrypoint. Shared supplement sections live under `paper/shared/supplemental/`. Deterministic supplement-only figures are generated by a focused Python composer into `paper/shared/figures/generated/supplement/` with a compact manifest. Tests enforce separation from the main PDF, no duplicated main figure/table labels, double-blind safety, and build target coverage.

**Tech Stack:** Python 3.10, `PIL`, `json`, `hashlib`, `pathlib`, LaTeX/LNCS ACCV template, BibTeX via existing shared `references.bib`, `pdfinfo`, `pdftoppm`, pytest.

accv-all: accv accv-supplement

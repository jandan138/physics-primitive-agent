# Superpowers Plans And Specs

This directory stores implementation specs and plans produced during agentic development.

## Layout

- `specs/`: design decisions and rationale.
- `plans/`: executable task lists with verification checkpoints.

## Rules

- Plans are process artifacts, not reviewer-facing DeepDive claims.
- When a plan changes project claims, update `docs/reference/claim-boundaries.md` or a dated
  record.
- Keep completed plans because they explain why the bootstrap skeleton is shaped this way.

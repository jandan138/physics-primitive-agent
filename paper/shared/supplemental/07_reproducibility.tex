\section{Implementation and Reproducibility Notes}

The repository separates small reviewer-facing paper artifacts from large raw assets and logs.
This section explains how the supplement is rebuilt and how the paper figures remain
auditable without committing raw 3D assets, videos, or run directories.

\paragraph{Build path.}
The ACCV supplement is a separate venue-local entrypoint. It inputs the same ACCV preamble as the
main paper, uses the shared bibliography, and remains in anonymous review mode. The main paper does
not input the supplement. This preserves ACCV self-contained-paper requirements while allowing the
supplementary PDF to provide derivations, explanatory diagrams, and provenance notes.

\paragraph{Figure generation.}
Supplement figures are rebuilt by the paper figure pipeline from figure specifications and compact
panel assets. The assets live with the other supplement figures and are accompanied by a manifest.
The manifest records the figure id, PDF/PNG names, file hashes, source-record references, and
claim-boundary text. Edits to titles, panels, or boundary text therefore change the recorded hash.

\paragraph{Regeneration commands.}
The intended local sequence is: generate supplement figures, build the ACCV supplement, and then
build the main ACCV PDF plus supplement together. The Makefile fallback also handles the case where
the supplement has no citations by skipping BibTeX only when the generated auxiliary file contains
no citation commands. Once citations are present, BibTeX runs normally.

\paragraph{Why raw assets are excluded.}
The artifact policy is not cosmetic. Collision packages are safety-affecting artifacts, and raw
asset mirrors, generated run directories, and logs can be large, license-sensitive, or
environment-specific. The paper therefore commits compact PDF/PNG outputs and records the
larger materials by anonymous artifact class and dated record. This keeps ACCV review reproducible
without turning the source repository into a raw asset bundle.

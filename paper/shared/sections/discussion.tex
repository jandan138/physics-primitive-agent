\section{Discussion}
\label{sec:discussion}

\paragraph{Why geometry-only selection is insufficient.}
The bed/Franka cylinder record shows that per-primitive geometric success is insufficient once package context changes compound body state and simulation labels.
The Phase~0 overlays extend the same lesson across candidate lanes: V-HACD, CoACD, CPD-style packages, and bounding primitives can all be useful proposals, but none is the acceptance criterion.
The proposed pipeline needs the diagnostic layer because the failure can appear only after the package is placed in a task scene with gravity, contact, support, and robot-body ownership.

\paragraph{Performance versus diagnostic acceptance.}
The contact-throughput microbenchmark motivates keeping accepted native primitives, but throughput alone cannot override a failed body-state or articulation gate.
This is why the throughput result remains scoped as a collision-only hook.
It motivates primitive packages after acceptance; it does not justify selecting a primitive package
that fails drop/settle, stack/slide, or link-boundary checks.

\paragraph{Evidence.}
Figures summarize package geometry, probe outcomes, body-state mechanisms, and link ownership.
They make the acceptance path inspectable, but do not add unrecorded runtime evidence, benchmark
evidence, robot operation evidence, or safety certification.

\paragraph{Limitations.}
The current evidence supports a diagnostic checker loop, a recorded bed/Franka body-state mechanism case, a narrow collision-only performance hook, a five-asset rigid Phase~0 gate audit, and one Franka generated-package consumption smoke.
It does not yet support a production compiler, calibrated default selector, validated COM/inertia repair, broad cylinder stability, broad benchmark superiority, robot manipulation performance, deployment readiness, real-world transfer, or safety certification.
Future work should broaden paired asset suites, add generated-package robot task probes, and test contact-operation settings before stronger benchmark or robot-operation claims are made.
